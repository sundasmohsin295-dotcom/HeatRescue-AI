## 🌟 Core Innovation: Closed-Loop Microclimate Response
Most climate platforms merely display static heat maps. **HeatRescue AI** operates a closed decision loop:

$$\text{Detect (40Guard)} \longrightarrow \text{Understand} \longrightarrow \text{Predict} \longrightarrow \text{Decide} \longrightarrow \text{Act (Dispatcher)} \longrightarrow \text{Verify}$$

Every decision is computed deterministically across 2-meter air temperature layers ($AGL$), persistence duration, and continuous solar radiation metrics.
